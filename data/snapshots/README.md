# Earlier EPA snapshots

This directory holds EPA exports that `data/raw/` used to contain. It is empty until a newer snapshot replaces the current one.

The changelog at `/data/changelog/` reads each `YYYY-MM-DD` folder plus the current files in `data/raw/`. It does not contact cfpub.epa.gov, and it does not invent a folder that was never committed.

When you save a newer export, copy the current files here first. The steps are in `data/raw/README.md`.
